# 🗄️ Fetch Data with AWS Lambda + DynamoDB  

This project will teach you how to **store and retrieve data using DynamoDB with AWS Lambda**.  
It’s the **Data Tier** in a **Three-Tier Architecture**, focusing on persistence and backend data retrieval.

## 📋 Project Overview  

- **Difficulty:** 🟨 Intermediate  
- **Time:** ⏱️ ~90 minutes  
- **Cost:** 💸 $0 (Free Tier eligible)  

### 🔑 Key Services  
- **Amazon DynamoDB**  
- **AWS Lambda**  

### 🔑 What You’ll Learn  
- 🗄️ Create a **DynamoDB table** to store user data  
- ✍️ Insert and manage **sample items** in DynamoDB  
- 🖥️ Implement an AWS **Lambda function** to fetch data  
- 🧪 Test Lambda functions with sample events  
- 🔐 Configure IAM **permissions for secure access**  
- 💎 Apply a **least-privilege security model** for DynamoDB  

---

👉 By the end of this project, you’ll have a **Lambda function connected to DynamoDB** that can retrieve user data — completing the **Data Tier** of your 3-tier solution.
