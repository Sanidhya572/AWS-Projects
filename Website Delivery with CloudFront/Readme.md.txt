# 🚀 Website Delivery with Amazon CloudFront  

This project will teach you how to **deploy a static website using Amazon S3 and distribute it globally with Amazon CloudFront**.  
It’s the first step in building a **Three-Tier Architecture**, focusing on the **Presentation Layer**.  

---

## 📋 Project Overview  

- **Difficulty:** 🟩 Easy Peasy  
- **Time:** ⏱️ 60 minutes  
- **Cost:** 💸 $0 (Free Tier eligible)  

### 🔑 Key Services  
- **Amazon S3**  
- **Amazon CloudFront**  

### 🔑 What You’ll Learn  
- 🪣 Create and manage Amazon **S3 buckets**  
- ⬆️ Upload and serve static website files  
- 🌐 Distribute content globally with **Amazon CloudFront**  
- 🔒 Secure your S3 buckets using **Origin Access Control (OAC)**  
- 💎 Compare **CloudFront vs. S3 static hosting** performance
