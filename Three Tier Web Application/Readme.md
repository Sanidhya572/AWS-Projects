## 📌 Overview
This project demonstrates how to build a **three-tier web application** using AWS services.  
The application follows a common cloud architecture pattern with three layers:  

- **Presentation Tier** → Amazon S3 and CloudFront for hosting and content delivery  
- **Logic Tier** → AWS Lambda and API Gateway for serverless backend logic  
- **Data Tier** → Amazon DynamoDB for scalable NoSQL storage  

---

## 🎯 What You Will Learn
By going through this project, you will:  
- Understand the **three-tier architecture model** (Presentation, Logic, Data)  
- Learn how to host a **static website** using **Amazon S3 + CloudFront**  
- Gain experience with **serverless backend development** using **Lambda & API Gateway**  
- Store and retrieve data from **DynamoDB**  
- Configure **CORS** and integrate frontend with backend APIs  
- Validate and troubleshoot using **CloudWatch logs and browser DevTools**  

---

## 🚀 Why This Project?
This architecture is widely used for **modern, cloud-native applications** because it is:  
- **Scalable** – Automatically handles more traffic as needed  
- **Cost-Effective** – Pay only for what you use  
- **Secure & Maintainable** – Clear separation of concerns across tiers
